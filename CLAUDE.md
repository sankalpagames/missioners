# Миссионеры

Игра про оператора, который через узкий сверхсветовой канал (512 бит/с) управляет биомашинами-«миссионерами» на далёкой планете. Всё, что видит игрок, физически прошло через канал.

Текущая цель — законченная одиночная point-and-click адвенчура (см. `docs/design.md` §1а). Сервер, фракции, PvP — потом.

## Документы — читать перед работой

- `docs/codex.md` — кодекс разработки: по каким правилам принимаются решения (одна реальность, честность как архитектура, одно чудо, физика вместо правил, режимы — данными, трение — выбор…). Каждый пункт с примером; читать первым, когда решение неочевидно.
- `docs/design.md` — дизайн: посылка, столпы, петля, принятые решения, открытые вопросы.
- `docs/tech.md` — техника: архитектура, модель канала, протокол, форматы пакетов, мир.
- `docs/roadmap.md` — родмапа: что дальше, что в следующих актах, что решено не делать. Сделанное переносить в «сделано» с датой.
- `docs/agent-api.md` — API для внешних агентов (ChatGPT, Claude, скрипт): стая (`/pack/…`, §1–9) и оператор платформы (`/op/…`, §10, виртуальная консоль `server/opconsole.js` — те же пакеты и байты, что у браузерной, текстом). Самодостаточный. Менять вместе с `intent`/`perceive` в `world.js`, `packApi`/`opApi` в `server/index.js`, декодерами консоли.
- `docs/art.md` — спрайты: генератор, настройки, шаблоны промптов, что режет фильтр, список листов, что генерить дальше. Читать перед любой генерацией картинок.

Если код и `docs/tech.md` расходятся — прав код, документ поправить в том же коммите.

## Публикация

GitHub Pages из корня (`.github/workflows/static.yml`) с ветки `main` — одиночная игра, сервер не нужен. Корневой `index.html` — онбординг для плейтестеров, кнопка открывает `proto/index.html` отдельным окном. Работа идёт в `main`. Ветка `mp` — только для выкатки на Azure: `git push origin main:mp`, когда хотим обновить сервер (деплой рвёт живые комнаты на полминуты, поэтому не на каждый коммит). Пуш в `mp` деплоит всё на Azure App Service F1 (`.github/workflows/mp_missioners.yml`, Linux, Node 22, `npm start`; WebSocket на Linux включён по умолчанию), сервер сам раздаёт клиента; GitHub Pages не участвует. Адрес: `https://missioners-gvbqaqg2ajfmahh8.centralus-01.azurewebsites.net/` (корень — лобби). Данные комнат — `/home/data` на App Service.

## Прототип `proto/`

Чистый JS, без сборки. Запуск: `python3 proto/serve.py` (конфиг `proto` в `.claude/launch.json`). Сетевой хост: `npm install` один раз, `node server/index.js 8777 debug` (конфиг `server`), консоль — `http://localhost:8777/index.html?room=test`; данные комнат — `data/` (не в репозитории). `debug` — правда о мире в шторку и телепорт; на сервере не включать. `level=ФАЙЛ` — поднять ещё одну карту сверх `proto/maps/` (экспорт из редактора).

- `world.js` — мир, Web Worker. Не знает о консоли.
- `maps/ID.js` — карты (уровни; `act1` — первый акт, `duel` — две станции и цепочка ретрансляторов к планшету, для батла), формат 2, слоями (`docs/design.md` §11г): `terrain` (расщелина, край, пятна рельефа), `sites`/`layouts` (площадки под базы и раскладка по числу платформ), `pois` (указатели: место с именем и текстом, не объект), `objects` (объекты с абсолютными координатами и своим id; `scenery` — примета, `collider` — свой коллайдер), `decor` (спрайты без описания), `pack` (стая). В `meta` — id, название, ревизия `v` и версия формата `format` (должна равняться `LEVEL_FORMAT` из кодовой книги, `levelCheck`; правила карты — `levelLint`). Хост выбирает карту по id (одиночная игра — `index.html?map=ID`, комната — `cfg.map`). Пишет редактор сериализатором `levelText` из кодовой книги; старые карты переводит `tools/level-convert.js`. Самих баз в уровне нет: платформ в мире столько, сколько поднял хост, база на площадке разворачивается по штатному составу `BASE` из кодовой книги.
- `terrain.js` — рельеф, расщелина, декорации (объект `TER`); `camera.js` — рендер кадра (объект `CAM`); `sprites.png` + `sprites.json` — атлас спрайтов, собирается `tools/sprites-build.js` из `tools/raw/` (не в репозитории; id ассетов — `tools/spritecook-assets.json`). Всё это — часть мира.
- `editor.html`, `editor.js` — редактор уровня, только localhost (`docs/tech.md` §11). Инструмент, не игра: читает мир напрямую; слои (тирейн, указатели, объекты, приметы, декор, базы, стая) с вкладкой и инструментами на слой, фильтр видимости, список правил карты; `?map=ID`, список карт (`GET /maps`), «сохранить» (ревизия +1) и «сохранить как…» через POST в `serve.py`.
- `spectate.html`, `spectate.js` — спектатор: проигрывает лог мира постфактум (`docs/tech.md` §12) или живьём с сервера (`?room=КОД`, зритель мир не запускает), карта, лента, характеристики при наведении. Инструмент, не игра. `mapdraw.js` — слой высот, общий с редактором.
- `link.js` — канал. Единственный путь мир → консоль.
- `station.js` — станция: мир + канал на каждую платформу в одном хосте, наружу только сообщения с номером платформы `st` (пакеты, потери, показания модема). Хосты: `station-worker.js` (воркер, одиночная игра) и `server/index.js` (Node, сетевые комнаты на 2…4 платформы, `index.html?room=КОД&st=k`). Консоль разницы не видит.
- `console.js` — консоль оператора. Видит только сообщения станции (`transport.onmessage`); канала у неё нет.
- `codebook.js` — кодовая книга типов; подключается и в мир, и в консоль.
- `index.html`, `style.css` — разметка; сноски через `data-tip`. `lobby.html` — лобби сетевой игры (корень сервера): имя оператора, список станций, вход по коду; только с сервером.

## Правила проекта

- **Консоль не читает мир.** Любая новая фича на экране должна получать данные через пакеты. Отладка — только в шторке `#drawer`, с пометкой «игрок этого не видит».
- **Решения мира — с заметкой.** Новый `if` с числами, от которого зависит игровой исход (рефлекс, отказ станции, смерть, потеря связи), пишет `note(kind, {…почему})` в лог мира (`docs/tech.md` §12). Заметки до консоли не доходят; читать — `node tools/log-read.js`.
- **Канал честный.** Новые виды данных получают реальный размер в байтах, класс (`bg`/`cmd`) и вид (`kind`); размеры и формулы дописываются в `docs/tech.md` §4–5.
- **Панель = подписка.** Новая панель имеет свой выключатель/интервал в шапке и счётчик Б/с; появляется в легенде вкладки «Канал».
- **Цель — единственный пространственный примитив.** Не добавлять отдельных «направлений», «точек взгляда» и т.п.
- **Слои карты** (`docs/design.md` §11г): указатель — место, не объект (без спрайта и действий); объект — с типом, спрайтом и коллайдером (одно свойство для ходьбы, лидара и обзора); примета — объект без функции (флаг для редактора); декор — кадр и лидар без описания. Объект не внутри чужого коллайдера. «Рядом» — одно число `REACH` (1 м до поверхности) для прибытия, осмотра и действия. Новый тип объекта — сразу запись в `SPRITES` или пометка в `docs/art.md` §8.
- **Одно чудо.** СВС-канал — единственная фантастика (односторонняя нора — его вторая форма, не второе чудо); остальное считать инженерно честно, абсолютные числа можно крутить, зависимости — нет.
- **Режимы различаются данными, не ветвлением.** Мир не знает, кто играет: получает число платформ и уровень. Никаких `if (multiplayer)` в `world.js`; правило, зависящее от «кто играет», — параметр комнаты, который хост отдаёт миру. Одиночная игра — частный случай «платформ = 1» и проверка сетевой. Сначала спросить, не даст ли правило физика сама (`docs/codex.md` §4–5).
- Интерфейс, лог и тексты станции — по-русски, включая радиожаргон («несущая» — сознательно, для атмосферы). Корпоративный инструментарий, пути, идентификаторы и служебные строки заставки — латиницей (ares-tk, ARK-041, DSE, FTL).
- **Тон текстов** — техническая информация, без местоимений второго лица и без «заботы». Без риторических противопоставлений («всплеск, не сверхскорость», «это X, а не Y») — просто факт: не «ты слеп между отсчётами», а «между отсчётами данных о теле нет». Дружелюбнее пульта МКС, но без объяснений очевидного. Это касается сносок, лога, сообщений об ошибках и текстов станции.
- **Заставка ведётся настоящими пакетами**: запрос статуса → ответ станции текстом → пульс → первая телеметрия → консоль. Цифры в заставке — из принятых байт, не из констант.
- **Совместимость сохранений.** Сохранение в браузере переживает деплой. При несовместимом изменении формата (снимок мира, структуры консоли, id объектов) поднять `SAVE_VERSION` в `console.js` — заставка предупредит и посоветует новый сеанс.
- Комментарии в коде — по-русски, короткие, в стиле существующих.

## Проверка

Синтаксис: `node -e "for(const f of ['proto/world.js','proto/link.js','proto/console.js','proto/codebook.js','proto/terrain.js','proto/camera.js','proto/maps/act1.js','proto/editor.js','proto/mapdraw.js','proto/spectate.js','proto/station.js','proto/station-worker.js']) new Function(require('fs').readFileSync(f,'utf8'))" && node --check server/index.js`.
Все headless-инструменты берут карту через `tools/map.js`: аргумент `map=ID` (или путь к файлу), иначе `act1`. Кадры камеры без браузера: `node tools/render-check.js` → `tools/out/render-check.png` (набор сцен или `x y gx gy` для одного кадра). Карта высот и изогипсы против рельефа: `node tools/hmap-check.js` (`old` — как было, для сравнения). Стая одичалых без браузера: `node tools/pack-check.js [режим тела] [1 — отбиваться]` — тело идёт по расщелине к планшету, печатает крики, события и смену состояний особей. Площадка агента стаи: `node tools/agent-play.js [ускорение] [voice=N]` — станция в node, лента восприятия печатается, намерения вводятся строками («О1: на запад далеко», «?» — картина, «> 60» — промотать, «жди» — до первой новой строки, как `perceive?wait`), отладочные команды помечены; лог мира → `data/play-*.log`. Спектатор: `http://localhost:8765/spectate.html?log=/log/play-….log` (или перетащить файл лога) — проигрывание постфактум с картой, лентой и характеристиками при наведении; на сервере `spectate.html?room=КОД` — то же живьём. Лог мира: `node tools/log-read.js data/КОД.log` (сервер) или файл с кнопки «лог мира» в шторке — лента решений мира и команд, сводка. Широкий кадр для шапки лендинга (`banner.png`): `node tools/banner.js` — варианты ракурсов, `node tools/banner.js k 480 120 3` — выбранный в полный размер. Поведение проверяется в браузере; в отладочной шторке есть телепорт (клик по карте «правда о мире») — ускоряет сценарии. Ускорение времени ×4 — в шапке. Лаборатория лидара: `index.html?lab` (с `serve.py` — `http://localhost:8765/index.html?lab`) — та же консоль и мир, канал без ограничений, клик по карте / стрелки — телепорт со снимком, сеанс не сохраняется. Работает только на localhost — на опубликованном сайте флаг игнорируется. Редактор уровня: `http://localhost:8765/editor.html` — карта высот, объекты, площадки с призраком базы, свободная камера, сохранение в `level.js`, импорт/экспорт карт файлом; после правки уровня прогнать `render-check` и `hmap-check`.
