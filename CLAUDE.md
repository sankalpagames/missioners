# Миссионеры

Игра про оператора, который через узкий сверхсветовой канал (512 бит/с) управляет биомашинами-«миссионерами» на далёкой планете. Всё, что видит игрок, физически прошло через канал.

Текущая цель — законченная одиночная point-and-click адвенчура (см. `docs/design.md` §1а). Сервер, фракции, PvP — потом.

## Документы — читать перед работой

- `docs/design.md` — дизайн: посылка, столпы, петля, принятые решения, открытые вопросы.
- `docs/tech.md` — техника: архитектура, модель канала, протокол, форматы пакетов, мир.
- `docs/roadmap.md` — родмапа: что дальше, что в следующих актах, что решено не делать. Сделанное переносить в «сделано» с датой.
- `docs/art.md` — спрайты: генератор, настройки, шаблоны промптов, что режет фильтр, список листов, что генерить дальше. Читать перед любой генерацией картинок.

Если код и `docs/tech.md` расходятся — прав код, документ поправить в том же коммите.

## Публикация

GitHub Pages из корня (`.github/workflows/static.yml`). Корневой `index.html` — онбординг для плейтестеров, кнопка открывает `proto/index.html` отдельным окном. Игра статическая, сервер не нужен.

## Прототип `proto/`

Чистый JS, без сборки. Запуск: `python3 proto/serve.py` (есть конфиг `proto` в `.claude/launch.json`).

- `world.js` — мир, Web Worker. Не знает о консоли.
- `terrain.js` — рельеф, расщелина, декорации (объект `TER`); `camera.js` — рендер кадра (объект `CAM`); `sprites.png` + `sprites.json` — атлас спрайтов, собирается `tools/sprites-build.js` из `tools/raw/` (не в репозитории; id ассетов — `tools/spritecook-assets.json`). Всё это — часть мира.
- `link.js` — канал. Единственный путь мир → консоль.
- `console.js` — консоль оператора. Видит только `link.onDeliver`.
- `codebook.js` — кодовая книга типов; подключается и в мир, и в консоль.
- `index.html`, `style.css` — разметка; сноски через `data-tip`.

## Правила проекта

- **Консоль не читает мир.** Любая новая фича на экране должна получать данные через пакеты. Отладка — только в шторке `#drawer`, с пометкой «игрок этого не видит».
- **Канал честный.** Новые виды данных получают реальный размер в байтах, класс (`bg`/`cmd`) и вид (`kind`); размеры и формулы дописываются в `docs/tech.md` §4–5.
- **Панель = подписка.** Новая панель имеет свой выключатель/интервал в шапке и счётчик Б/с; появляется в легенде вкладки «Канал».
- **Цель — единственный пространственный примитив.** Не добавлять отдельных «направлений», «точек взгляда» и т.п.
- **Одно чудо.** СВС-канал — единственная фантастика; остальное считать инженерно честно, абсолютные числа можно крутить, зависимости — нет.
- Интерфейс, лог и тексты станции — по-русски, включая радиожаргон («несущая» — сознательно, для атмосферы). Корпоративный инструментарий, пути, идентификаторы и служебные строки заставки — латиницей (ares-tk, ARK-041, DSE, FTL).
- **Тон текстов** — техническая информация, без местоимений второго лица и без «заботы». Без риторических противопоставлений («всплеск, не сверхскорость», «это X, а не Y») — просто факт: не «ты слеп между отсчётами», а «между отсчётами данных о теле нет». Дружелюбнее пульта МКС, но без объяснений очевидного. Это касается сносок, лога, сообщений об ошибках и текстов станции.
- **Заставка ведётся настоящими пакетами**: запрос статуса → ответ станции текстом → пульс → первая телеметрия → консоль. Цифры в заставке — из принятых байт, не из констант.
- **Совместимость сохранений.** Сохранение в браузере переживает деплой. При несовместимом изменении формата (снимок мира, структуры консоли, id объектов) поднять `SAVE_VERSION` в `console.js` — заставка предупредит и посоветует новый сеанс.
- Комментарии в коде — по-русски, короткие, в стиле существующих.

## Проверка

Синтаксис: `node -e "for(const f of ['proto/world.js','proto/link.js','proto/console.js','proto/codebook.js','proto/terrain.js','proto/camera.js']) new Function(require('fs').readFileSync(f,'utf8'))"`.
Кадры камеры без браузера: `node tools/render-check.js` → `tools/out/render-check.png` (набор сцен или `x y gx gy` для одного кадра). Карта высот и изогипсы против рельефа: `node tools/hmap-check.js` (`old` — как было, для сравнения). Широкий кадр для шапки лендинга (`banner.png`): `node tools/banner.js` — варианты ракурсов, `node tools/banner.js k 480 120 3` — выбранный в полный размер. Поведение проверяется в браузере; в отладочной шторке есть телепорт (клик по карте «правда о мире») — ускоряет сценарии. Ускорение времени ×4 — в шапке. Лаборатория лидара: `index.html?lab` (с `serve.py` — `http://localhost:8765/index.html?lab`) — та же консоль и мир, канал без ограничений, клик по карте / стрелки — телепорт со снимком, сеанс не сохраняется.
