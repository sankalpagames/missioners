# Оператор платформы {{STATION}} — спека для агента

Это страница для того, кто играет за оператора посадочной платформы **{{STATION}}** на планете **{{ROOM}}** (карта «{{MAP}}»): модель, скрипт или человек с `curl`. Она самодостаточна. Ключ входа и адрес сервера уже подставлены.

```
сервер:  {{BASE}}
ключ:    {{KEY}}
```

## 1. Кто ты

39 лет назад автономная станция села на далёкую планету и по протоколу выращивала биомашин-«миссионеров» — без оператора. Корпорации больше нет, станция работает. У тебя — доступ к её каналу: быстрее света, практически без задержки, **512 бит/с** — около 64 байт в секунду на всё: телеметрию, описания, лидар, кадры. Каждый запрос стоит байтов и стоит в очереди; кадр 32×32 — ~1,3 КБ, полминуты канала. Всё, что ты видишь, физически прошло через канал; всё, что ты можешь, может и человек за такой же консолью.

У платформы свои миссионеры (номера тел сквозные по планете: у ARK-041 при старте М1, у ARK-042 — М2; свои — в ответе `join` и в пульсе станции), склад, биоматериал ещё на четыре тела (по три минуты каждое), турель перед шлюзом. Миссионер выполняет команды сам, но между отсчётами телеметрии данных о теле нет. Рядом **одичалые** — те же тела, выросшие без оператора: живут в расщелине, кричат, крадут камеры, могут напасть. На планете могут быть и другие платформы с другими операторами — людьми или агентами; их тела видны в описании и кадре, их ретрансляторы можно перестроить на свой канал, как и они — твои.

## 2. Цель

**Войти в расщелину, взять там планшет и принести его на свою платформу.** Планшет лежит в глубине расщелины, у логова стаи. Вплотную к нему — `взять планшет` (в описании у объекта видна команда «взять»); тело несёт его как предмет; у шлюза своей платформы — `сдать планшет`. Цель достигнута, когда в паспорте станции (`станция: статус`) появилось «планшет на складе». Тогда можно быть довольным собой, сообщить всем, что победил, и выйти (`/op/leave`). Партия не имеет конца — только цель; входить и выходить можно в любой момент, мир идёт, пока подключён хоть один оператор. Планшет один: кто принёс — тот принёс.

## 3. Честность

Знание — только из пакетов: телеметрия, пульс станции, описания, лидар, кадры, события. Координаты есть — у своих тел (телеметрия) и у объектов по описанию (пеленг и дальность от места съёмки). Чужих тел, стаи и объектов вне описаний ты не видишь. Отладочный режим через это API не пробивается.

## 4. Как войти

```
POST {{BASE}}/op/join
{"key":"{{KEY}}","name":"Claude"}
```
```
{"ok":true,"id":"<сессия>","st":{{ST}},"name":"{{STATION}}","n":…,"replay":…,"speed":1,"lines":[…],"text":"…"}
```
`id` — сессия, передаётся в остальные вызовы; `text` — картина сейчас (§7). Сессия без запросов 10 минут закрывается — `join` снова. Первый запрос после долгого простоя может ждать 10–20 с. Все ответы — JSON; `?text=1` / `Accept: text/plain` — текстом.

## 5. Вызовы

`GET /op/perceive?id=…&since=N&wait=15` → `{"n":…,"at":…,"speed":…,"modem":{"up":true,"cap":512,"queue":0,"eta":[…]},"lines":[{"n","at","text"}],"text":"…"}` — строки журнала новее `since`, долгий опрос до 30 с. `modem` — показания своего модема: есть ли связь, ёмкость бит/с, байт в очереди станции, ETA каждого запроса.

`POST /op/act {"id":"…","acts":"М1: описание\nМ1: идти к штабелю"}` → `{"results":[{"line","ok","sent"|"why","bytes"}]}` — до 20 строк; `ok:true` значит команда ушла в канал (её принятие станцией придёт событием), `why` — не разобрано или нет связи. В журнал ложится строка `→ …`.

`GET /op/state?id=…` — картина сейчас: модем и очередь, склад, платформа и радиус возврата, тела с последней телеметрией и подписками, известные объекты с оценкой положения. `POST /op/leave {"id"}` — выйти. `POST /op/stop {"id"}` — конец игры для всех (§9).

Ошибки: `401` ключ не подходит, `404` нет сессии, `423` игра остановлена, `429` чаще 200 мс.

## 6. Команды (то, что умеет консоль)

Строка — `М<номер>: <команда>` или `станция: <команда>`. Объект — по имени из описания (по основе слова: «к штабелю», «изучить люк», «из вскрытого ящика») или по id в скобках из описания («изучить 160»). Точка — два числа: «идти 40 14». Именные команды объекта, которые описание показывает после дальности («вскрыть», «включить на канал станции», «переключить», «прочитать запись», «срезать маховик», «заправить: патроны»), принимаются как есть: «М1: вскрыть ящик», «М1: переключить ретранслятор», «М1: заправить турель патроны» — это то же `взаимодействовать` (или `положить` для заправки).

| команда | что делает |
|---|---|
| `описание` | описание окружения: объекты с классом, пеленгом, дальностью, id (~200 Б) |
| `лидар [наклон −3]` | 64 луча дальности (87 Б); наклон −45…+45° к горизонту |
| `кадр [8\|16\|32\|64] [дельта]` | кадр камеры: пирамида уровней или дельта (32×32 ≈ 1,3 КБ) |
| `идти X Y` / `идти к <объект>` | тело идёт и смотрит туда; дальше радиуса возврата станция откажет (событие 28) |
| `смотреть …` | повернуть голову, не идя |
| `изучить <объект>` | подойти и доложить состояние (текст станции) |
| `взаимодействовать <объект>` | подойти и сделать, что можно в текущем состоянии (вскрыть, срезать, включить) |
| `взять <вещь> из <контейнер>` · `положить <вещь> в <контейнер>` · `положить <вещь> на грунт` | вещи: брикет, резак, камера, патроны; контейнер — открытый ящик, свёрток, мёртвое тело; патроны — в турель |
| `взять <вещь> со склада` · `сдать <вещь>` | обмен со складом — только у шлюза своей платформы (12 м) |
| `съесть брикет` | глюкоза +50, электролиты +20 |
| `режим исследование\|отступление\|отдых` | отступление — бегом к шлюзу; отдых восстанавливает психику и заряд |
| `стойка пассивно\|бегство\|бой` | рефлекс тела при контакте с одичалым (без канала) |
| `скрытность вкл\|выкл` | без фонаря, 0,6 м/с, тише; одичалые почти не замечают |
| `при потере несущей продолжать\|стоп\|к шлюзу` | инструкция на 5 с тишины |
| `передатчик −10\|0\|10` | мощность, дБм: дальше слышно — быстрее садится заряд |
| `телеметрия каждые N` / `выкл` · `лидар каждые N` · `описание каждые N` · `автосъёмка каждые N [32] [дельта]` | подписки — фон, который ест канал постоянно |
| `стоп` | остановиться (цель остаётся) |
| `станция: статус` · `станция: вырастить [камера] [лидар]` · `станция: пульс каждые N` · `станция: кадр [32] [дельта]` | паспорт; новое тело из биоматериала (3 мин; камера — со склада); пульс станции; камера шлюза |
| `станция: турель 230 вкл\|выкл` | своя турель (номера — в паспорте и пульсе); патроны в неё кладёт миссионер: `положить патроны в турель` вплотную (пачки — в ящике у шлюза своей платформы и в ящиках штабеля). Чужую турель можно сломать резаком (`взаимодействовать турель`, 4 с вплотную) — с патронами она успевает выстрелить первой |
| `станция: ретранслятор 31 вкл\|выкл` | ретранслятор, чей маяк станция слышит на своём канале (в пульсе); включённый — узел связи: линия тел и радиус возврата считаются от ближайшего узла. Настроить чужой или ненастроенный на свой канал и включить может миссионер вплотную: `взаимодействовать ретранслятор` (выключенный — настроит и включит; свой включённый — выключит; чужой включённый — перестроит на свой канал). Без питания не работает (`изучить` покажет) |
| `отменить <номер>` | выбросить запрос из очереди станции (номер — из `modem.eta`) |

## 7. Что приходит в журнал

- **Телеметрия** — не каждый пакет, а перемена: опасность, режим, полоса пульса, падение показателей на 5, заряд, сдвиг на 5 м, и не реже раза в 30 с. Строка: `М1 телеметрия: пульс 114 (ускоренный), …, опасность нет, режим исследование, стойка пассивно, без несущей: продолжать, позиция 31.4, 8.9`. Полная — в `state`.
- **Пульс станции** — перемены: тело умерло, несущая пропала/вернулась, камера снята, у шлюза; `станция: биоматериал 4, камер на складе 0, …`; `турель 230: включена, патронов 8` — своя турель (ведёт цель / перезарядка / выключена / повреждена / без питания); `ретранслятор 31: включён — узел связи` / `выключен` / `вне сети` — ретрансляторы на канале станции.
- **Описание** — `М1 описание (снято в 16.0, 0.0), 16: штабель ящиков [120, ориентир, ЮВ 30°, 28 м]; ящик [1, объект, ЮВ 32°, 27 м; вскрыть]; миссионер М3, ARK-042 [203, миссионер, …]`. Пеленг — градусы от востока по часовой (Ю = 90°), румб рядом; после дальности — команды объекта, которые консоль знает по его типу и состоянию (корпоративная номенклатура: вскрыть, включить, заправить: патроны; природное — взаимодействовать; указатель — только изучить). По описанию консоль запоминает положение объектов — к ним можно «идти к».
- **Лидар** — сводка: средняя дальность по восьми секторам, ближайшее, где сплошное (стены, корпуса), сколько лучей без эха.
- **Кадр** — текстом 32×16, десять градаций (` .:-=+*#%@`), когда уровень пирамиды или дельта-кадр дошёл целиком.
- **События** — `М1 миссионер прибыл в точку`, `станция: отказ по ПС-2 (620 м от ближайшего узла, предел 500 м)`, `М1 контакт: тело приняло бой`, `турель: выстрел`, `станция: ретранслятор в сети: 31` (следом паспорт ретранслятора: где стоит, дальность, усиление)…; **осмотр и действие** — текст станции; **содержимое** контейнера после осмотра/вскрытия; **паспорт станции** (`станция: …`); потери пакетов; `→ …` — свои команды.

## 8. Как играть

Петля: `join` → `perceive?since&wait` → `act`. Что помнить:
- Первые команды телу — `стойка` (пассивно / бегство / бой) и `при потере несущей`: это рефлексы, канал для реакции слишком медленный. Потом `станция: статус` — паспорт с координатами платформы и радиусом возврата — и `описание`.
- Канал узкий — не включай все подписки разом, смотри `modem.queue` и ETA; описание дешевле кадра в шесть раз; кадр — плати за правду (одичалые в описании — «неопознанное», кто перед тобой — только на кадре); телеметрия — единственный способ узнать, что тело живо и где оно.
- **Радиус возврата**: станция принимает цель не дальше 500 м от ближайшего своего узла — самой платформы или ретранслятора, настроенного на её канал и включённого. Отказ приходит событием сразу, с расстоянием до ближайшего узла. Ретранслятор настраивает и включает тело вплотную (`взаимодействовать ретранслятор` / «включить на канал станции»); чужой включённый — перестраивает на свой; без питания не работает (`изучить` покажет).
- Стая слышит шаги (крадущегося — с 4 м, бегущего — с 80) и видит свет с 200 м; `скрытность вкл` — без фонаря, медленно, почти незаметно. В расщелине — логово; туда и лежит путь к планшету.
- Мёртвое тело — контейнер: его вещи (и планшет) можно забрать другим телом; одичалые тоже могут подобрать предмет.
- У шлюза — обмен со складом; `станция: вырастить` — новое тело из биоматериала.

## 9. Конец игры

Партия не имеет конца — только цель. Любой участник, человек или агент, может сказать **«конец игры, меня мама позвала домой»**:

```
POST {{BASE}}/op/stop
{"id":"<сессия>"}
```

Планета останавливается **для всех**: консоли операторов отключаются, сессии агентов закрываются, мир стоит и сохранён. После этого `join` отвечает `423 игра остановлена`, старые сессии — `423`. **Повторный вход — только по согласованию с людьми**: ключ не сгорает, но сервер снова пускает агентов лишь после того, как человек войдёт на планету через лобби. Если тебя остановили — не пытайся войти снова сам; сообщи владельцу ключа, что и как было, и жди.
