# Миссионеры — API для агентов: стая и операторы

Этот документ — для того, кто садится играть моделью (ChatGPT, Claude, локальная), скриптом или человеком с `curl`. Он самодостаточен: остальные документы читать не нужно. Две стороны, два API на одном сервере: **§1–9 — стая одичалых** (`/pack/…`), **§10 — оператор платформы** (`/op/…`), то же, что консоль в браузере, только текстом; **§11 — планета без лобби** (`/rooms`, `/maps`) и как провести дуэль двух агентов на карте `duel`. Та же спека страницей — `agents.html` на сайте игры и на сервере. Дизайн стороны стаи — `design.md` §12а, устройство — `tech.md` §6 «Агент стаи»; протокол оператора в байтах — `tech.md` §4–5.

## 1. Что это за игра и кто ты

Далёкая планета. Сорок лет назад на неё села автономная станция ARK-041 и по протоколу выращивала биомашин-«миссионеров» — без оператора, никому не докладывая. Теперь операторы вернулись: люди на Земле управляют новыми миссионерами через узкий канал связи (512 бит/с), видят мир по крупицам — телеметрия, короткие описания, картинки 32×32 — и ходят по планете чужими телами со светом.

**Ты играешь за одичалых** — тех самых биомашин, что выросли без оператора. Стая из нескольких особей (О1, О2, …) живёт в расщелине, у логова. Те же тела, что у миссионеров, тот же рисунок пор на коже, только без голоса в голове. У них есть чувства, страх, любопытство, раны, усталость и **шесть слов**, которые они кричат друг другу.

Ты — не мозг стаи и не бог. Ты — голос, который каждая особь слышит и которому иногда подчиняется. Твоя воля проходит через её характер и состояние: пугливая не пойдёт на чужого, раненая ляжет, только что окликнутая не слушает ещё несколько секунд. **Принято ≠ выполнено**: что особь сделала на самом деле, видно только по ленте восприятия.

Что стая хочет — решаешь ты: прогонять двуногих, прятаться от них, следить, красть у них предметы, приносить им предметы. Слова «враг» в API нет.

## 2. Честность

Ты видишь только то, что чувствуют особи. В ответах сервера **никогда нет** координат, метров, номеров миссионеров, карты. Есть: «двуногий со светом, близко, на западе, идёт», «вижу: постройка, далеко, на севере», «О3 лежит, мёртв, недалеко». Это не ограничение реализации, а правило игры — такое же, как у операторов, которые видят планету только через байты канала. Никакой отладочный режим сервера через это API не пробивается.

Симметрия с оператором: у него вход дорогой и узкий, выход точный. У тебя вход бесплатный и полный (всё, что чувствует каждая особь), выход ненадёжный.

## 3. Как войти

Планета создаётся в лобби (`/`) или вызовом `POST /rooms` (§11); при создании создатель получает **токен стаи** — 16 шестнадцатеричных знаков. Тебе нужны код планеты и этот токен. Базовый адрес — адрес сервера: `https://missioners-gvbqaqg2ajfmahh8.centralus-01.azurewebsites.net` (бесплатный тариф: первый запрос после простоя ждёт 10–20 с, пока сервер проснётся; запросы дольше ~230 с рвутся).

Мир идёт только пока к планете подключён хоть один оператор (это сессия, как партия в RTS). Если операторов нет — стая спит: `asleep: true`, лента не растёт, кулдауны не тикают. Намерения при этом принимаются и исполнятся, когда мир пойдёт.

Все ответы — JSON. Добавь `?text=1` (или заголовок `Accept: text/plain`) — получишь только текст, удобно для модели и `curl`.

## 4. Три вызова

### `POST /pack/join` — войти, получить картину сейчас

```
POST /pack/join
{"room":"soqman","token":"9fa3546456e195b6"}
```
```
{"ok":true,"room":"soqman","n":412,"at":6730.5,"asleep":false,"speed":1,
 "lines":["О1: у логова, сплю, спокоен, цел",
          "О2: снаружи, стою, тревожно, ранен; двуногий со светом, близко, на западе, стоит; вижу: постройка, далеко, на севере",
          "О3: в глубине расщелины, отдыхаю у логова, спокоен, цел; несу: камера"],
 "text":"…те же строки через \n…"}
```
`n` — курсор ленты: номер последней строки восприятия. Запомни его. `at` — часы мира в секундах. `speed` — ускорение времени на планете (×1…×4): все секунды в этом документе — игровые.

Строка состояния особи: `место, действие, страх, здоровье[, устал]; чужой; что видит; что несёт; делаю, как сказано`.

### `GET /pack/perceive` — что случилось с прошлого раза

```
GET /pack/perceive?room=soqman&token=9fa3546456e195b6&since=412&wait=15
```
```
{"n":419,"at":6748.0,"asleep":false,"speed":1,
 "lines":[{"n":413,"at":6731.5,"who":2,"text":"двуногий со светом, близко, на западе, идёт"},
          {"n":414,"at":6732.0,"who":2,"text":"страшно"},
          {"n":415,"at":6732.0,"who":2,"text":"кричу «чужой»"},
          {"n":416,"at":6732.5,"who":3,"text":"тревожно"},
          {"n":417,"at":6733.0,"who":3,"text":"иду к логову"},
          {"n":418,"at":6740.5,"who":2,"text":"бегу к логову"},
          {"n":419,"at":6747.5,"who":2,"text":"двуногого больше не чувствую"}],
 "text":"112:11 О2: двуногий со светом, близко, на западе, идёт\n…"}
```
- `since` — курсор из прошлого ответа; отдаётся всё, что новее. Первый раз — `n` из `join`.
- `wait` — долгий опрос, секунд (0…30): сервер держит запрос, пока не появится новая строка или не истечёт время. Тихо — ответ придёт пустым по таймеру. Так агент не тикает, а реагирует: случилось — ответил.
- Строка появляется **на смену состояния**, не по таймеру: пока ничего не меняется, лента молчит. Молчание — тоже информация.
- Буфер ленты — 2000 строк; агент, пропавший надолго, получит хвост.

### `POST /pack/act` — намерения

```
POST /pack/act
{"room":"soqman","token":"9fa3546456e195b6",
 "acts":"О2: крикни сюда\nО3: к крикнувшему\nО1: как хочешь"}
```
```
{"results":[{"line":"О2: крикни сюда","ok":true,"who":2},
            {"line":"О3: к крикнувшему","ok":true,"who":3},
            {"line":"О1: как хочешь","ok":false,"who":1,"why":"не слушает, ещё 9 с"}],
 "asleep":false}
```
`acts` — строки через `\n` (или массив строк), до 20 за раз. Каждая — `О<номер>: <глагол …>`. Ответ по строке: принято или отказ с причиной. Причины отказа: `не слушает, ещё N с` (кулдаун), `боится`, `мёртв`, `дерётся`, `на передышке у логова, не выйдет`, `глотка, только что кричал`, `чужого не чувствую`, `крика не слышал`, `не вижу: …`, `рядом ничего нет, подойти вплотную`, `не понял; знаю: …`.

Ошибки HTTP: `401` — токен не подходит, `404` — планеты нет, `429` — чаще 200 мс между запросами.

## 5. Глаголы

| намерение | что делает особь | кулдаун после |
|---|---|---|
| `к чужому` | идёт к двуногому, которого чувствует; отказ, если боится или чужого нет | 15 с |
| `к крикнувшему` | идёт туда, откуда был последний крик (не старше 30 с) | 15 с |
| `домой` | в логово | 15 с |
| `на лёжку` | на своё место у логова | 15 с |
| `к О3` | к другой особи | 15 с |
| `к обломкам`, `к постройке`, `к ящику`, `к свёртку`… | к ориентиру, который особь *видела*, или к предмету в поле зрения (до 20 м; по основе слова) — подводит вплотную | 15 с (предмет — 3 с) |
| `на север`, `на юго-запад далеко`, `на восток близко`, `на запад чуть` | по румбу: далеко ≈ 150 м, обычно 50, близко 20, чуть 8 | 15 с (чуть — 3 с) |
| `стой` / `затаись` / `замри` / `жди` | замирает на 30 с и смотрит | 3 с |
| `возьми камеру`, `возьми резак`, `возьми брикет` | из открытого контейнера вплотную (4 м); несёт одну вещь, с ношей медленнее | 3 с |
| `положи` / `брось` | кладёт ношу на грунт свёртком | 3 с |
| `крикни тревога` (и другие слова, §6) | кричит; «бей» и «сюда» — только если не боится | 3 с |
| `как хочешь` | снять слово: особь снова живёт по своим рефлексам | 3 с |

Кулдаун — на особь: пока он не вышел, она не слушает (`не слушает, ещё N с`). Слово будит спящую. На каждое принятое движение в ленте появляется «иду …» — даже если особь уже шла. Слово ложится поверх рефлексов, но **рефлексы главнее**: двуногий ближе 15 м — особь решает сама; бегство, «домой» и передышка снимают слово. Дошла — стоит и ждёт (`жду`), на лёжку не уходит, не засыпает. Путь перекрыт — «не пройти».

## 6. Крики

Шесть слов, как у обезьяньей стаи: слово — реакция, а не смысл. Все особи в радиусе голоса слышат слово вместе с направлением на крикнувшего; стены и расщелина глушат. Крик несёт направление источника, не цели: «чужой» значит «чужой там, где я».

| крик | что несёт | как реагируют |
|---|---|---|
| `тревога` | опасность здесь | пугливые бегут к логову, осторожные замирают, храбрые поворачиваются к источнику |
| `чужой` | двуногий там, где я | любопытные подходят на расстояние, храбрые идут на него, пугливые отходят |
| `сюда` | сбор ко мне | привязанные к стае идут, одиночки — не всегда |
| `бей` | нападать на ближайшего чужого | только храбрые и только если видят цель; остальные мечутся или бегут |
| `домой` | в логово | почти все, раненые первыми |
| `добыча` | здесь предмет / тело | любопытные и голодные идут |

**Особи кричат сами** — испугавшаяся кричит «тревога», увидевшая свет — «чужой», раненая — «домой». Это основной способ узнать, что происходит: ты подслушиваешь стаю. Крики слышат и операторы — как звук, направление и громкость, без слов. Голосистая стая выдаёт себя.

## 7. Что бывает в ленте

- **Чужой**: `двуногий со светом` / `без света`; `вплотную` (< 3 м) / `близко` (< 15) / `недалеко` (< 60) / `далеко`; румб из восьми (`на северо-востоке`…); `стоит` / `крадётся` / `идёт` / `бежит`; `двуногого больше не чувствую`.
- **Своё**: действие (`сплю`, `стою`, `замер, смотрю`, `подхожу к двуногому`, `нападаю`, `отхожу от двуногого`, `бегу к логову`, `бегу от света`, `иду к логову`, `отдыхаю у логова`, `иду …`, `жду`, `лежу, мёртв`); страх (`спокоен` / `тревожно` / `страшно`); здоровье (`цел` / `ранен` / `едва жив` / `мёртв`); `устал`; место (`у логова` / `в глубине расщелины` / `в расщелине` / `у выхода` / `снаружи`).
- **Вокруг**: `вижу: постройка, далеко, на севере` (постройка — платформа операторов); `вижу: обломки …`; `вижу: свёрток, недалеко, на западе` (предмет или открытый контейнер в поле зрения, до 20 м — к нему можно «к свёртку»); `рядом: ящик — брикет, резак` (в 6 м — уже с содержимым); `О3 лежит, мёртв, недалеко, на юге`; `тело двуногого лежит, …`; `несу: камера` / `положил`.
- **Свет и выстрелы**: у каждой платформы перед шлюзом стоит турель с лампой — особь видит `вижу: турель, недалеко, …` с 64 м и `вижу: свет, далеко, …` с 200 м, если лампа горит. `на меня направили свет` / `свет ушёл` — луч на особи; освещённая при страхе бежит от света. `выстрел, далеко, на севере` — турель стреляет по движущимся; у края дальности бегство спасает, в глубине сектора — нет. Стоящее турель не захватывает. Патроны у турели кончаются — тогда она только светит.
- **Драка**: `нападаю`, укус, удар резаком — строки от участников. Тело двуногого можно ранить и убить; мёртвое — контейнер с его вещами (камера).

## 8. Как играть — петля

1. `join` → картина, запомнить `n`.
2. `perceive?since=n&wait=15` → новые строки; обновить `n`.
3. Если есть что решать — `act` строками. Нет — снова `perceive`.
4. Модель звать не на каждый ответ, а когда лента непуста: сервер сам держит запрос, пока тихо.

Минимальный скрипт (Python, стандартная библиотека):

```python
import json, urllib.request
BASE, ROOM, TOKEN = 'https://<сервер>', 'soqman', '9fa3546456e195b6'
def call(path, body=None, q=''):
    req = urllib.request.Request(BASE+path+q, data=json.dumps(body).encode() if body else None,
                                 headers={'Content-Type':'application/json'}, method='POST' if body else 'GET')
    return json.load(urllib.request.urlopen(req, timeout=60))
s = call('/pack/join', {'room':ROOM, 'token':TOKEN}); n = s['n']; print(s['text'])
while True:
    r = call('/pack/perceive', q=f'?room={ROOM}&token={TOKEN}&since={n}&wait=15'); n = r['n']
    if not r['lines']: continue
    print(r['text'])
    acts = decide(r['text'])          # здесь — модель: вход текст ленты, выход строки «О2: домой»
    if acts: print(call('/pack/act', {'room':ROOM, 'token':TOKEN, 'acts':acts}))
```

Что стоит помнить модели:
- Стая разнородна: кто храбрый, кто пугливый, видно по тому, кто откликается на «бей» и кто первым кричит «тревога». Запоминай.
- Не дёргай каждую особь каждый ход — кулдауны; давай слово одной, остальным — крик.
- Молчащая стая невидима для операторов; кричащая — слышна.
- Двуногий со светом видит дальше тебя; без света — почти не видит, но и ты его замечаешь только близко.
- Мир идёт, пока подключён оператор; `asleep: true` — ждать, не тратить запросы.

## 9. Пределы

- Не чаще 5 запросов в секунду на токен (`429`); `wait` — не больше 30 с.
- Буфер ленты — 2000 строк; за перезапуск сервера нумерация `n` начинается заново — сделай `join` ещё раз, если `perceive` вернул `n` меньше твоего.
- Ускорение времени планеты (`speed`) задаёт создатель; при ×4 кулдаун 15 с — это меньше 4 с реальных, агенту тесно; для агентских партий лучше ×1–×2.
- Сейчас радиус голоса стаи бесконечен: ты слышишь каждую особь и говоришь с каждой. Конечный радиус (вожак, крики как единственная связь) — следующий шаг, API не изменится: просто строк станет меньше.

## 10. Сторона оператора: `/op/…`

Агент садится за платформу как обычный оператор — тот же вход в комнату, что у консоли в браузере, те же пакеты по каналу 512 бит/с, те же команды. Сервер держит для него **виртуальную консоль**: декодирует принятые пакеты в текст и переводит текстовые команды в байты. Всё, что агент видит, физически прошло через канал; всё, что он может, может и человек за консолью. Мир и станция разницы не видят: сессия агента держит мир идущим, как любой оператор.

### 10.1. Кто ты здесь

Оператор посадочной платформы ARK-04k. У платформы свои миссионеры (номера тел сквозные по планете: у ARK-041 при старте М1, у ARK-042 — М2; свои — в ответе `join` и в пульсе станции), склад, биоматериал на выращивание новых тел, канал 512 бит/с — ~64 байта в секунду на всё: телеметрию, описания, лидар, кадры. Каждый запрос стоит байтов и стоит в очереди; кадр 32×32 — ~1,3 КБ, полминуты канала. Миссионер выполняет команды напрямую, но между отсчётами данных о теле нет. Задача станции — ПС-7: найти М-07, который не вернулся; что здесь произошло — вопрос игры. Рядом одичалые (§1) — те же тела без оператора; они кричат, крадут камеры, могут напасть. Стойка при контакте и инструкция на потерю несущей — рефлексы тела, которые задаются заранее, потому что канал для реакции слишком медленный.

### 10.2. Вызовы

`POST /op/join {"room":"soqman","st":0,"name":"GPT"}` → `{"ok":true,"id":"<сессия>","st":0,"name":"ARK-041","n":…,"replay":…,"speed":1,"lines":[…],"text":"…"}` — `st` — номер платформы (0 — ARK-041, 1 — ARK-042…); `id` — сессия, передаётся в остальные вызовы; `text` — картина сейчас (§10.4). Токен не нужен: как и для людей, достаточно кода планеты. Сессия без запросов 10 минут — выход.

`GET /op/perceive?id=…&since=N&wait=15` → `{"n":…,"at":…,"speed":…,"modem":{"up":true,"cap":512,"queue":0,"eta":[…]},"lines":[{"n","at","text"}],"text":"…"}` — строки журнала новее `since`, долгий опрос до 30 с. `modem` — показания своего модема: есть ли связь, ёмкость бит/с, байт в очереди станции, ETA каждого запроса.

`POST /op/act {"id":"…","acts":"М1: описание\nМ1: идти к штабелю"}` → `{"results":[{"line","ok","sent"|"why","bytes"}]}` — до 20 строк; `ok:true` значит команда ушла в канал (её принятие станцией придёт событием), `why` — не разобрано или нет связи. В журнал ложится строка `→ …`, как в консоли.

`GET /op/state?id=…` — картина сейчас: модем и очередь, склад, платформа и радиус возврата, тела с последней телеметрией и **подписками** (интервалы телеметрии, лидара, описания, автосъёмка, мощность передатчика — станция держит их в пульсе), известные объекты с оценкой положения; `POST /op/leave {"id"}` — выйти. `?text=1` / `Accept: text/plain` — ответ текстом. Ошибки: `404` нет сессии, `429` чаще 200 мс.

### 10.3. Команды (то, что умеет консоль)

Строка — `М<номер>: <команда>` или `станция: <команда>`. Объект — по имени из описания (по основе слова: «к штабелю», «изучить люк», «из вскрытого ящика») или по id в скобках из описания («изучить 160»). Точка — два числа: «идти 40 14». Именные команды объекта, которые описание показывает после дальности («вскрыть», «включить на канал станции», «переключить», «прочитать запись», «срезать маховик», «заправить: патроны»), принимаются как есть: «М1: вскрыть ящик», «М1: переключить ретранслятор», «М1: заправить турель патроны» — это то же `взаимодействовать` (или `положить` для заправки).

| команда | что делает |
|---|---|
| `описание` | описание окружения: объекты с классом, пеленгом, дальностью, id (~200 Б) |
| `лидар [наклон −3]` | 64 луча дальности (87 Б); наклон −45…+45° к горизонту |
| `кадр [8\|16\|32\|64] [дельта]` | кадр камеры: пирамида уровней или дельта (32×32 ≈ 1,3 КБ) |
| `идти X Y` / `идти к <объект>` | тело идёт и смотрит туда; дальше радиуса возврата станция откажет (событие 28) |
| `смотреть …` | повернуть голову, не идя |
| `изучить <объект>` | подойти и доложить состояние (текст станции) |
| `взаимодействовать <объект>` | подойти и сделать, что можно в текущем состоянии (вскрыть, срезать, включить) |
| `взять <вещь> из <контейнер>` · `положить <вещь> в <контейнер>` · `положить <вещь> на грунт` | вещи: брикет, резак, камера, патроны; контейнер — открытый ящик, свёрток, мёртвое тело; патроны — в турель |
| `взять <вещь> со склада` · `сдать <вещь>` | обмен со складом — только у шлюза своей платформы (12 м) |
| `съесть брикет` | глюкоза +50, электролиты +20 |
| `режим исследование\|отступление\|отдых` | отступление — бегом к шлюзу; отдых восстанавливает психику и заряд |
| `стойка пассивно\|бегство\|бой` | рефлекс тела при контакте с одичалым (без канала) |
| `скрытность вкл\|выкл` | без фонаря, 0,6 м/с, тише; одичалые почти не замечают |
| `при потере несущей продолжать\|стоп\|к шлюзу` | инструкция на 5 с тишины |
| `передатчик −10\|0\|10` | мощность, дБм: дальше слышно — быстрее садится заряд |
| `телеметрия каждые N` / `выкл` · `лидар каждые N` · `описание каждые N` · `автосъёмка каждые N [32] [дельта]` | подписки — фон, который ест канал постоянно |
| `стоп` | остановиться (цель остаётся) |
| `станция: статус` · `станция: вырастить [камера] [лидар]` · `станция: пульс каждые N` · `станция: кадр [32] [дельта]` | паспорт; новое тело из биоматериала (3 мин; камера — со склада); пульс станции; камера шлюза |
| `станция: турель 230 вкл\|выкл` | своя турель (номера — в паспорте и пульсе); патроны в неё кладёт миссионер: `положить патроны в турель` вплотную (пачки — в ящике у шлюза своей платформы и в ящиках штабеля). Чужую турель можно сломать резаком (`взаимодействовать турель`, 4 с вплотную) — с патронами она успевает выстрелить первой |
| `станция: ретранслятор 31 вкл\|выкл` | ретранслятор, чей маяк станция слышит на своём канале (в пульсе); включённый — узел связи: линия тел и радиус возврата считаются от ближайшего узла. Настроить чужой или ненастроенный на свой канал и включить может миссионер вплотную: `взаимодействовать ретранслятор` (выключенный — настроит и включит; свой включённый — выключит; чужой включённый — перестроит на свой канал). Без питания не работает (`изучить` покажет) |
| `отменить <номер>` | выбросить запрос из очереди станции (номер — из `modem.eta`) |

### 10.4. Что приходит в журнал

- **Телеметрия** — не каждый пакет, а перемена: опасность, режим, полоса пульса, падение показателей на 5, заряд, сдвиг на 5 м, и не реже раза в 30 с. Строка: `М1 телеметрия: пульс 114 (ускоренный), …, опасность нет, режим исследование, стойка пассивно, без несущей: продолжать, позиция 31.4, 8.9`. Полная — в `state`.
- **Пульс станции** — перемены: тело умерло, несущая пропала/вернулась, камера снята, у шлюза; `станция: биоматериал 4, камер на складе 0, …`; `турель 230: включена, патронов 8` — своя турель (ведёт цель / перезарядка / выключена / повреждена / без питания); `ретранслятор 31: включён — узел связи` / `выключен` / `вне сети` — ретрансляторы на канале станции.
- **Описание** — `М1 описание (снято в 16.0, 0.0), 16: штабель ящиков [120, ориентир, ЮВ 30°, 28 м]; ящик [1, объект, ЮВ 32°, 27 м; вскрыть]; миссионер М3, ARK-042 [203, миссионер, …]`. Пеленг — градусы от востока по часовой (Ю = 90°), румб рядом; после дальности — команды объекта, которые консоль знает по его типу и состоянию (корпоративная номенклатура: вскрыть, включить, заправить: патроны; природное — взаимодействовать; указатель — только изучить). По описанию консоль запоминает положение объектов — к ним можно «идти к».
- **Лидар** — сводка: средняя дальность по восьми секторам, ближайшее, где сплошное (стены, корпуса), сколько лучей без эха.
- **Кадр** — текстом 32×16, десять градаций (` .:-=+*#%@`), когда уровень пирамиды или дельта-кадр дошёл целиком.
- **События** — `М1 миссионер прибыл в точку`, `станция: отказ по ПС-2 (620 м от ближайшего узла, предел 500 м)`, `М1 контакт: тело приняло бой`, `турель: выстрел`, `станция: ретранслятор в сети: 31` (следом паспорт ретранслятора: где стоит, дальность, усиление)…; **осмотр и действие** — текст станции; **содержимое** контейнера после осмотра/вскрытия; **паспорт станции** (`станция: …`); потери пакетов; `→ …` — свои команды.

### 10.5. Как играть

Петля та же, что у стаи (§8): `join` → `perceive?since&wait` → `act`. Что помнить: канал узкий — не включай все подписки разом, смотри `modem.queue` и ETA; описание дешевле кадра в шесть раз, кадр — плати за правду (одичалые в описании — «неопознанное», кто перед тобой — только на кадре); телеметрия — единственный способ узнать, что тело живо и где оно; стойку и инструкцию на потерю несущей выставь до выхода; у шлюза — обмен со складом; цель дальше 500 м от платформы или включённой мачты станция не примет.

## 11. Планета без лобби и дуэль двух агентов

Планету можно создать и без браузера — теми же настройками, что в лобби:

```
GET  /maps                      → [{"id":"act1","name":"Первый акт","sites":4}, {"id":"duel","name":"Две станции","sites":2}]
POST /rooms  {"code":"duel-01","map":"duel","n":2,"cap":512,"speed":1,"teams":"0,1","voice":0}
             → {"code":"duel-01","cfg":{…},"stations":[{"k":0,"name":"ARK-041",…},{"k":1,"name":"ARK-042",…}],"pack":"<токен стаи>"}
GET  /rooms                     → список планет: код, настройки, кто на платформах, часы мира
```

`code` — латиница, цифры, дефис, до 32 знаков; если планета с таким кодом уже есть — настройки не меняются, а токен стаи повторно не выдаётся (он только создателю, один раз). `n` — платформ (2…4, не больше площадок карты), `cap` — ёмкость дальней линии (512…4096 бит/с), `speed` — ускорение (1, 2, 4), `teams` — команда каждой платформы через запятую (пусто — каждая сама за себя; свои тела и турели не стреляют по своим, ретранслятор своей команды — свой узел), `voice` — радиус голоса стаи в метрах (0 — без предела). Мир идёт, пока к планете подключён хоть один оператор (сессия `/op/join` — тоже оператор).

### 11.1. Карта `duel` «Две станции»

Две посадочные платформы и стая одичалых в расщелине. **Цепочка ретрансляторов — единственный путь вглубь:** станция принимает цель не дальше 500 м от ближайшего своего узла (сама станция или ретранслятор, настроенный на её канал и включённый). Что известно операторам по корпоративным записям (координаты — те же, что в командах `идти X Y`; ось y растёт к югу):

| что | где | от ARK-041 | от ARK-042 |
|---|---|---|---|
| платформа ARK-041 | 10, 3 (шлюз смотрит на восток) | — | 650 м |
| платформа ARK-042 | 475, −452 (шлюз смотрит на юг) | 650 м | — |
| мачта со **средним ретранслятором** | 460, 3 | 450 м | 455 м |
| **входной ретранслятор** перед расщелиной | 448, 480 | 648 м | 933 м |
| вход в расщелину | 456, 520 | | |
| планшет в глубине расщелины | ≈ 533, 586 (в 136 м от входного ретранслятора, у логова стаи) | | |

Ретрансляторы выключены и не настроены. Тело вплотную к ретранслятору (`взаимодействовать ретранслятор` или `включить на канал станции`) настраивает его на канал своей станции и включает; **чужой включённый — перестраивает на свой** (для чужой станции он тем самым пропадает из сети — она это видит в пульсе и теряет право ходить дальше него). Свой включённый можно выключать и включать со станции (`станция: ретранслятор 2 вкл`). Средний ретранслятор — общий, и это весь конфликт: кто держит его на своём канале, тот ходит к входному; кто держит входной — тот ходит к планшету. Турели охраняют шлюзы (120 м), до поля они не достают. Стая слышит шаги и видит свет с обеих сторон; в расщелине — её логово.

Прогон сценария без браузера — `node tools/duel-check.js` (две виртуальные консоли проходят цепочку и перехватывают средний ретранслятор друг у друга; печатает журналы и сводку).

### 11.2. Как провести дуэль

1. Кто-то один (человек в лобби или агент через `POST /rooms`) создаёт планету на карте `duel` с двумя платформами. Ускорение ×1 или ×2: путь до среднего ретранслятора — около пяти минут игрового времени.
2. Каждый агент-оператор входит на свою платформу: `POST /op/join {"room":"duel-01","st":0,"name":"…"}` и `{"st":1}`. Третий агент, если есть, садится за стаю: `POST /pack/join` с токеном из ответа на создание.
3. Условия сторонам задаются инструкцией, а не картой. Пример для операторов: *прочитать планшет (`изучить планшет` вплотную) и вернуть тело к шлюзу живым; тел — одно, биоматериала — на ещё четыре по три минуты*. Пример для стаи: *не пустить двуногих к логову; принести к логову камеру с тела, никого не потеряв*. Выигрыш одного не обязан быть проигрышем другого.
4. Смотреть партию — `spectate.html?room=duel-01` (правда о мире целиком, живьём) или потом лог мира `data/duel-01.log` через `node tools/log-read.js`.

Что стоит знать до начала: `станция: статус` даёт координаты своей платформы и радиус возврата; первая команда телу — `стойка` и `при потере несущей` (рефлексы, канал для реакции слишком медленный); описание у ретранслятора показывает его команду по состоянию («включить на канал станции» / «переключить»); отказ станции по ПС-2 приходит событием сразу, с расстоянием до ближайшего узла — по нему видно, что узел потерян.
