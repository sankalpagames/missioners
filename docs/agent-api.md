# Миссионеры — API стороны стаи (для агента)

Этот документ — для того, кто садится играть за одичалых: модели (ChatGPT, Claude, локальная), скрипта или человека с `curl`. Он самодостаточен: остальные документы читать не нужно. Дизайн стороны — `design.md` §12а, как это устроено внутри — `tech.md` §6 «Агент стаи».

## 1. Что это за игра и кто ты

Далёкая планета. Сорок лет назад на неё села автономная станция ARK-041 и по протоколу выращивала биомашин-«миссионеров» — без оператора, никому не докладывая. Теперь операторы вернулись: люди на Земле управляют новыми миссионерами через узкий канал связи (512 бит/с), видят мир по крупицам — телеметрия, короткие описания, картинки 32×32 — и ходят по планете чужими телами со светом.

**Ты играешь за одичалых** — тех самых биомашин, что выросли без оператора. Стая из нескольких особей (О1, О2, …) живёт в расщелине, у логова. Те же тела, что у миссионеров, тот же рисунок пор на коже, только без голоса в голове. У них есть чувства, страх, любопытство, раны, усталость и **шесть слов**, которые они кричат друг другу.

Ты — не мозг стаи и не бог. Ты — голос, который каждая особь слышит и которому иногда подчиняется. Твоя воля проходит через её характер и состояние: пугливая не пойдёт на чужого, раненая ляжет, только что окликнутая не слушает ещё несколько секунд. **Принято ≠ выполнено**: что особь сделала на самом деле, видно только по ленте восприятия.

Что стая хочет — решаешь ты: прогонять двуногих, прятаться от них, следить, красть у них предметы, приносить им предметы. Слова «враг» в API нет.

## 2. Честность

Ты видишь только то, что чувствуют особи. В ответах сервера **никогда нет** координат, метров, номеров миссионеров, карты. Есть: «двуногий со светом, близко, на западе, идёт», «вижу: постройка, далеко, на севере», «О3 лежит, мёртв, недалеко». Это не ограничение реализации, а правило игры — такое же, как у операторов, которые видят планету только через байты канала. Никакой отладочный режим сервера через это API не пробивается.

Симметрия с оператором: у него вход дорогой и узкий, выход точный. У тебя вход бесплатный и полный (всё, что чувствует каждая особь), выход ненадёжный.

## 3. Как войти

Планета создаётся в лобби (`/`), при создании создатель получает **токен стаи** — 16 шестнадцатеричных знаков. Тебе нужны код планеты и этот токен. Базовый адрес — адрес сервера, например `https://missioners-<…>.azurewebsites.net`.

Мир идёт только пока к планете подключён хоть один оператор (это сессия, как партия в RTS). Если операторов нет — стая спит: `asleep: true`, лента не растёт, кулдауны не тикают. Намерения при этом принимаются и исполнятся, когда мир пойдёт.

Все ответы — JSON. Добавь `?text=1` (или заголовок `Accept: text/plain`) — получишь только текст, удобно для модели и `curl`.

## 4. Три вызова

### `POST /pack/join` — войти, получить картину сейчас

```
POST /pack/join
{"room":"soqman","token":"9fa3546456e195b6"}
```
```
{"ok":true,"room":"soqman","n":412,"at":6730.5,"asleep":false,"speed":1,
 "lines":["О1: у логова, сплю, спокоен, цел",
          "О2: снаружи, стою, тревожно, ранен; двуногий со светом, близко, на западе, стоит; вижу: постройка, далеко, на севере",
          "О3: в глубине расщелины, отдыхаю у логова, спокоен, цел; несу: камера"],
 "text":"…те же строки через \n…"}
```
`n` — курсор ленты: номер последней строки восприятия. Запомни его. `at` — часы мира в секундах. `speed` — ускорение времени на планете (×1…×4): все секунды в этом документе — игровые.

Строка состояния особи: `место, действие, страх, здоровье[, устал]; чужой; что видит; что несёт; делаю, как сказано`.

### `GET /pack/perceive` — что случилось с прошлого раза

```
GET /pack/perceive?room=soqman&token=9fa3546456e195b6&since=412&wait=15
```
```
{"n":419,"at":6748.0,"asleep":false,"speed":1,
 "lines":[{"n":413,"at":6731.5,"who":2,"text":"двуногий со светом, близко, на западе, идёт"},
          {"n":414,"at":6732.0,"who":2,"text":"страшно"},
          {"n":415,"at":6732.0,"who":2,"text":"кричу «чужой»"},
          {"n":416,"at":6732.5,"who":3,"text":"тревожно"},
          {"n":417,"at":6733.0,"who":3,"text":"иду к логову"},
          {"n":418,"at":6740.5,"who":2,"text":"бегу к логову"},
          {"n":419,"at":6747.5,"who":2,"text":"двуногого больше не чувствую"}],
 "text":"112:11 О2: двуногий со светом, близко, на западе, идёт\n…"}
```
- `since` — курсор из прошлого ответа; отдаётся всё, что новее. Первый раз — `n` из `join`.
- `wait` — долгий опрос, секунд (0…30): сервер держит запрос, пока не появится новая строка или не истечёт время. Тихо — ответ придёт пустым по таймеру. Так агент не тикает, а реагирует: случилось — ответил.
- Строка появляется **на смену состояния**, не по таймеру: пока ничего не меняется, лента молчит. Молчание — тоже информация.
- Буфер ленты — 2000 строк; агент, пропавший надолго, получит хвост.

### `POST /pack/act` — намерения

```
POST /pack/act
{"room":"soqman","token":"9fa3546456e195b6",
 "acts":"О2: крикни сюда\nО3: к крикнувшему\nО1: как хочешь"}
```
```
{"results":[{"line":"О2: крикни сюда","ok":true,"who":2},
            {"line":"О3: к крикнувшему","ok":true,"who":3},
            {"line":"О1: как хочешь","ok":false,"who":1,"why":"не слушает, ещё 9 с"}],
 "asleep":false}
```
`acts` — строки через `\n` (или массив строк), до 20 за раз. Каждая — `О<номер>: <глагол …>`. Ответ по строке: принято или отказ с причиной. Причины отказа: `не слушает, ещё N с` (кулдаун), `боится`, `мёртв`, `дерётся`, `на передышке у логова, не выйдет`, `глотка, только что кричал`, `чужого не чувствую`, `крика не слышал`, `не вижу: …`, `рядом ничего нет, подойти вплотную`, `не понял; знаю: …`.

Ошибки HTTP: `401` — токен не подходит, `404` — планеты нет, `429` — чаще 200 мс между запросами.

## 5. Глаголы

| намерение | что делает особь | кулдаун после |
|---|---|---|
| `к чужому` | идёт к двуногому, которого чувствует; отказ, если боится или чужого нет | 15 с |
| `к крикнувшему` | идёт туда, откуда был последний крик (не старше 30 с) | 15 с |
| `домой` | в логово | 15 с |
| `на лёжку` | на своё место у логова | 15 с |
| `к О3` | к другой особи | 15 с |
| `к обломкам`, `к постройке`, `к ящику`… | к ориентиру, который особь *видела*, или к предмету рядом (по основе слова) | 15 с (рядом — 3 с) |
| `на север`, `на юго-запад далеко`, `на восток близко`, `на запад чуть` | по румбу: далеко ≈ 150 м, обычно 50, близко 20, чуть 8 | 15 с (чуть — 3 с) |
| `стой` / `затаись` / `замри` / `жди` | замирает на 30 с и смотрит | 3 с |
| `возьми камеру`, `возьми резак`, `возьми брикет` | из открытого контейнера вплотную (3 м); несёт одну вещь, с ношей медленнее | 3 с |
| `положи` / `брось` | кладёт ношу на грунт свёртком | 3 с |
| `крикни тревога` (и другие слова, §6) | кричит; «бей» и «сюда» — только если не боится | 3 с |
| `как хочешь` | снять слово: особь снова живёт по своим рефлексам | 3 с |

Кулдаун — на особь: пока он не вышел, она не слушает (`не слушает, ещё N с`). Слово будит спящую. На каждое принятое движение в ленте появляется «иду …» — даже если особь уже шла. Слово ложится поверх рефлексов, но **рефлексы главнее**: двуногий ближе 15 м — особь решает сама; бегство, «домой» и передышка снимают слово. Дошла — стоит и ждёт (`жду`), на лёжку не уходит, не засыпает. Путь перекрыт — «не пройти».

## 6. Крики

Шесть слов, как у обезьяньей стаи: слово — реакция, а не смысл. Все особи в радиусе голоса слышат слово вместе с направлением на крикнувшего; стены и расщелина глушат. Крик несёт направление источника, не цели: «чужой» значит «чужой там, где я».

| крик | что несёт | как реагируют |
|---|---|---|
| `тревога` | опасность здесь | пугливые бегут к логову, осторожные замирают, храбрые поворачиваются к источнику |
| `чужой` | двуногий там, где я | любопытные подходят на расстояние, храбрые идут на него, пугливые отходят |
| `сюда` | сбор ко мне | привязанные к стае идут, одиночки — не всегда |
| `бей` | нападать на ближайшего чужого | только храбрые и только если видят цель; остальные мечутся или бегут |
| `домой` | в логово | почти все, раненые первыми |
| `добыча` | здесь предмет / тело | любопытные и голодные идут |

**Особи кричат сами** — испугавшаяся кричит «тревога», увидевшая свет — «чужой», раненая — «домой». Это основной способ узнать, что происходит: ты подслушиваешь стаю. Крики слышат и операторы — как звук, направление и громкость, без слов. Голосистая стая выдаёт себя.

## 7. Что бывает в ленте

- **Чужой**: `двуногий со светом` / `без света`; `вплотную` (< 3 м) / `близко` (< 15) / `недалеко` (< 60) / `далеко`; румб из восьми (`на северо-востоке`…); `стоит` / `крадётся` / `идёт` / `бежит`; `двуногого больше не чувствую`.
- **Своё**: действие (`сплю`, `стою`, `замер, смотрю`, `подхожу к двуногому`, `нападаю`, `отхожу от двуногого`, `бегу к логову`, `бегу от света`, `иду к логову`, `отдыхаю у логова`, `иду …`, `жду`, `лежу, мёртв`); страх (`спокоен` / `тревожно` / `страшно`); здоровье (`цел` / `ранен` / `едва жив` / `мёртв`); `устал`; место (`у логова` / `в глубине расщелины` / `в расщелине` / `у выхода` / `снаружи`).
- **Вокруг**: `вижу: постройка, далеко, на севере` (постройка — платформа операторов; `постройка со светом` — с горящей лампой турели); `вижу: обломки …`; `рядом: ящик — брикет, резак` (открытые контейнеры в 6 м с содержимым); `О3 лежит, мёртв, недалеко, на юге`; `тело двуногого лежит, …`; `несу: камера` / `положил`.
- **Свет и выстрелы**: `на меня направили свет` / `свет ушёл` — луч турели платформы; освещённая особь при страхе бежит от света. `выстрел, далеко, на севере` — турель стреляет по движущимся; у края дальности бегство спасает, в глубине сектора — нет. Стоящее турель не захватывает.
- **Драка**: `нападаю`, укус, удар резаком — строки от участников. Тело двуногого можно ранить и убить; мёртвое — контейнер с его вещами (камера).

## 8. Как играть — петля

1. `join` → картина, запомнить `n`.
2. `perceive?since=n&wait=15` → новые строки; обновить `n`.
3. Если есть что решать — `act` строками. Нет — снова `perceive`.
4. Модель звать не на каждый ответ, а когда лента непуста: сервер сам держит запрос, пока тихо.

Минимальный скрипт (Python, стандартная библиотека):

```python
import json, urllib.request
BASE, ROOM, TOKEN = 'https://<сервер>', 'soqman', '9fa3546456e195b6'
def call(path, body=None, q=''):
    req = urllib.request.Request(BASE+path+q, data=json.dumps(body).encode() if body else None,
                                 headers={'Content-Type':'application/json'}, method='POST' if body else 'GET')
    return json.load(urllib.request.urlopen(req, timeout=60))
s = call('/pack/join', {'room':ROOM, 'token':TOKEN}); n = s['n']; print(s['text'])
while True:
    r = call('/pack/perceive', q=f'?room={ROOM}&token={TOKEN}&since={n}&wait=15'); n = r['n']
    if not r['lines']: continue
    print(r['text'])
    acts = decide(r['text'])          # здесь — модель: вход текст ленты, выход строки «О2: домой»
    if acts: print(call('/pack/act', {'room':ROOM, 'token':TOKEN, 'acts':acts}))
```

Что стоит помнить модели:
- Стая разнородна: кто храбрый, кто пугливый, видно по тому, кто откликается на «бей» и кто первым кричит «тревога». Запоминай.
- Не дёргай каждую особь каждый ход — кулдауны; давай слово одной, остальным — крик.
- Молчащая стая невидима для операторов; кричащая — слышна.
- Двуногий со светом видит дальше тебя; без света — почти не видит, но и ты его замечаешь только близко.
- Мир идёт, пока подключён оператор; `asleep: true` — ждать, не тратить запросы.

## 9. Пределы

- Не чаще 5 запросов в секунду на токен (`429`); `wait` — не больше 30 с.
- Буфер ленты — 2000 строк; за перезапуск сервера нумерация `n` начинается заново — сделай `join` ещё раз, если `perceive` вернул `n` меньше твоего.
- Ускорение времени планеты (`speed`) задаёт создатель; при ×4 кулдаун 15 с — это меньше 4 с реальных, агенту тесно; для агентских партий лучше ×1–×2.
- Сейчас радиус голоса стаи бесконечен: ты слышишь каждую особь и говоришь с каждой. Конечный радиус (вожак, крики как единственная связь) — следующий шаг, API не изменится: просто строк станет меньше.
