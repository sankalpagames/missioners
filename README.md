# Миссионеры

Игра про оператора, который через узкий сверхсветовой канал общается с автономной посадочной станцией АРК-041 и исследует планету через «миссионеров» — биомашины с датчиками.

## Прототип канала

`proto/` — браузерный прототип: мир (Web Worker) → канал (честная модель: SNR → ёмкость, BER/PER, FEC/ARQ, планировщик) → консоль оператора. Консоль видит только байты, прошедшие через канал.

Запуск:

```bash
python3 proto/serve.py
```

и открыть http://localhost:8765. Отладочная шторка — кнопка «⚙ отладка».
