# Миссионеры

Игра про оператора, который через узкий сверхсветовой канал (512 бит/с) общается с автономной посадочной станцией ARK-041 и исследует планету через «миссионеров» — биомашины с датчиками. Всё, что видит игрок, физически прошло через канал.

Документы — в `docs/`: `codex.md` (правила принятия решений), `design.md` (дизайн), `tech.md` (архитектура, канал, протокол), `roadmap.md`, `agent-api.md` (API для внешних агентов), `art.md` (спрайты). Правила работы с кодом — `CLAUDE.md`.

## Режимы консоли

Одна и та же `proto/index.html`; различаются хостом станции и флагами URL, консоль разницы не видит.

- **Одиночная** — `index.html`. Станция (мир + канал) в Web Worker в браузере, сохранение в браузере. Отладочная шторка — три быстрых нажатия на «⚙ отладка»: физика канала, правда о мире с телепортом, очередь пакетов, кнопка «лог мира». Игрок этого не видит.
- **Лаборатория лидара** — `index.html?lab`. Та же консоль и мир, канал без ограничений, клик по карте / стрелки — телепорт со снимком, сеанс не сохраняется. Только localhost, на опубликованном сайте флаг игнорируется.
- **Сетевая** — `index.html?room=КОД&st=k`. Станция на сервере, WebSocket `/ws?room=КОД`; 2…4 платформы в одном мире, несколько операторов на одной платформе делят канал. Отладки нет, ускорение — настройка комнаты.

Параметры, которые хост отдаёт миру (`docs/tech.md` §6): `st=N` — число платформ, `teams=a,b,…` — команда каждой платформы, `voice=N` — радиус голоса стаи, `lab`.

## Запуск

Прототип — чистый JS, без сборки.

```bash
python3 proto/serve.py
```

и открыть http://localhost:8765 (консоль), `/editor.html`, `/spectate.html`. `serve.py` отдаёт статику без кэша, лог мира из `data/` (`GET /log/ИМЯ`), список карт (`GET /maps`) и принимает карты от редактора (`POST /maps/ID.js`) — только с loopback.

Сетевой хост:

```bash
npm install
node server/index.js 8777 debug
```

Лобби — http://localhost:8777/, консоль — `index.html?room=test`. Аргументы: `[порт] [debug] [level=ФАЙЛ]` (или `PORT`, `DATA_DIR`, `DEBUG=1`, `LEVEL_FILE`). `debug` — правда о мире в шторку и телепорт, на сервере не включать. Карты — все `proto/maps/*.js`, у каждой комнаты своя (`map` в `POST /rooms`, иначе `act1`; `GET /maps` — список); `level=ФАЙЛ` — ещё одна карта сверх них. Данные комнат — `data/` (не в репозитории).

Конфиги `.claude/launch.json`: `proto` (8765), `site` (8766, корень — лендинг), `server` (8777, с `debug`).

## API для агентов (только сервер)

`docs/agent-api.md`. Стая одичалых — `POST /pack/join`, `GET /pack/perceive`, `POST /pack/act`; оператор платформы — `/op/join`, `/op/perceive`, `/op/act`, `/op/state`, `/op/leave` через виртуальную консоль `server/opconsole.js` (те же пакеты и байты, что у браузерной, текстом). Служебные: `GET /rooms`, `POST /rooms`.

## Инструменты `tools/` (node, без браузера)

| Скрипт | Что делает |
|---|---|
| `render-check.js` | Кадры камеры → `tools/out/render-check.png`; набор сцен или `x y gx gy` для одного кадра. |
| `hmap-check.js` | Карта высот и изогипсы консоли против рельефа (`old` — как было). |
| `pack-check.js` | Стая одичалых: тело идёт по расщелине, печатает крики, события, смену состояний. `[режим тела] [стойка]`. |
| `agent-play.js` | Площадка агента стаи: станция в node, лента печатается, намерения вводятся строками. `[ускорение] [voice=N]`; лог → `data/play-*.log`. |
| `duel-check.js` | Карта `duel` без браузера: две виртуальные консоли (`server/opconsole.js`) проходят цепочку ретрансляторов и перехватывают средний друг у друга; журналы обеих сторон, сводка, код возврата 1, если конфликт не сошёлся. `[тихо]`. |
| `log-read.js` | Лог мира → текст: лента, `stats`, отрезок времени. |
| `banner.js` | Широкий кадр для шапки лендинга (`banner.png`): варианты ракурсов, затем `k W H ×`. |
| `sprites-build.js` | `tools/raw/*.png` → `proto/sprites.png` + `sprites.json` (см. `docs/art.md`). |

Проверка синтаксиса — команда в `CLAUDE.md`, раздел «Проверка».
