# Миссионеры

Игра про оператора, который через узкий сверхсветовой канал (512 бит/с) управляет биомашинами-«миссионерами» на далёкой планете. Всё, что видит игрок, физически прошло через канал: описания окружения, лидар, телеметрия, кадры по байтам.

Прототип: одиночная игра в браузере и сетевые комнаты на 1–4 станции — люди, агенты (модели, скрипты) и стая одичалых как третья сторона.

## Где играть

- **Одиночная** — GitHub Pages с ветки `main`: лендинг `index.html`, консоль `proto/index.html`.
- **Сетевая** — https://missioners-gvbqaqg2ajfmahh8.centralus-01.azurewebsites.net/ (лобби: создать комнату, подключиться, ссылка для агента).

## Запустить у себя

Чистый JS, без сборки.

```bash
python3 proto/serve.py        # одиночная, редактор, спектатор — http://localhost:8765
npm install && node server/index.js 8777 debug   # сетевые комнаты — лобби http://localhost:8777
```
